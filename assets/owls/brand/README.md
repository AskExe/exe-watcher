# Supplied Watcher logo

The two SVG files are unchanged copies of the selected logos supplied on October 16, 2026. The gold-on-dark version is the reference for native artwork, app icons and the README animation. The accepted contrast details are defined by `selection.json`: centered dark details on gold artwork and white highlights on black artwork. The native owl rig uses the same selection. Regenerate native/static assets with `mac/Scripts/build-owl-icons.sh`.

The README uses `../readme-owl.gif` (6 seconds, infinite loop); `../readme-owl-still.png` is a static fallback. Editable source and validation are in `videos/watcher-owl-motion/` at the repository root. These assets are Watcher branding, not copied from CodeBurn.
